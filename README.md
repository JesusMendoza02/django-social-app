# Django Social Network Platform

A full-stack social network web application built with **Django** and containerized using **Docker** and **Docker Compose** for streamlined deployment and service orchestration.

---

## 📌 Features

* User authentication and custom profile management.
* Social feeds, post publishing, and interactive user interactions.
* Modular Django application architecture.
* Database migrations and isolated environments managed via Docker.

---

## 🛠 Tech Stack

* **Backend:** Python, Django
* **Database:** MariaDB
* **DevOps & Containers:** Docker, Docker Compose
* **Frontend:** HTML5, CSS3, JavaScript
